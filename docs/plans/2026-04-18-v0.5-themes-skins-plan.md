# v0.5.0 Thèmes + Skins — Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (inline) ou superpowers:subagent-driven-development pour exécuter ce plan task-by-task.

**Goal :** Ajouter 6 thèmes (palettes) et 6 skins (formes de rendu) configurables via `config.toml`, avec TUI étendue. Le rendu sans config reste identique à v0.4 (défaut `m365princess` + `powerline`).

**Architecture :** Introduire `trait Skin` (stratégie de rendu) + `SegmentKind` (sémantique des segments) pour permettre au skin `bullet` de réinterpréter les jauges. Extraire les couleurs de `config.rs` vers `src/theme.rs` (const compilés, zéro I/O). Skins dans `src/skins/` (un fichier par skin). TUI réutilise son design data-driven pour exposer deux nouveaux panneaux.

**Tech Stack :**
- Rust 2021
- Pas de nouvelle dépendance (thèmes en `const`, skins en modules)
- `toml` + `ratatui` déjà présents depuis v0.3/v0.4

**Design doc source :** `docs/plans/2026-04-18-roadmap-design.md` (Release 2)

**Branche :** commits directs sur `main`. Co-author Claude Opus 4.7 obligatoire.

**Principe non-négociable :** rétro-compat stricte. Tous les golden tests existants doivent passer sans modification. Défaut = `theme = "m365princess"` + `skin = "powerline"` == v0.4 pixel-identique.

**Numérotation :** v0.4.0 a déjà été consommé par le TUI (écart vs roadmap d'origine). Cette release sera donc **v0.5.0**, et les métriques deviendront v0.6.0.

```rust
use crate::segments::{SegmentRich, SegmentRows};
use crate::theme::Theme;

pub trait Skin: Sync {
    fn name(&self) -> &'static str;
    fn render(&self, rows: &SegmentRows, theme: &Theme, cols: usize, suffix: &str) -> String;
}

/// Applique la troncature par priorité : drop les segments de priorité la plus haute
/// jusqu'à ce que la largeur visible passe sous `cols - suffix_width`.
/// Retourne les segments restants dans leur ordre original.
pub fn fit_segments(segments: &[SegmentRich], cols: usize, suffix_width: usize)
    -> Vec<SegmentRich>
{
    // Stratégie identique à build_powerline actuel : on calcule la largeur,
    // on drop le segment de priorité la plus haute tant que ça déborde.
    let mut kept: Vec<(usize, SegmentRich)> = segments.iter()
        .cloned()
        .enumerate()
        .collect();

    loop {
        let total_width = estimate_width(&kept) + suffix_width;
        if total_width <= cols || kept.is_empty() {
            break;
        }
        // Trouver l'index du segment de priorité la plus haute (numérique).
        // Sur égalité, on prend le dernier en ordre d'insertion (stable).
        let victim = kept.iter()
            .enumerate()
            .max_by_key(|(_, (_, s))| s.priority)
            .map(|(i, _)| i);
        match victim {
            Some(i) => { kept.remove(i); }
            None => break,
        }
    }

    kept.into_iter().map(|(_, s)| s).collect()
}

/// Largeur visible approximative (display_width du text de chaque segment + 2 pour le padding).
/// Les skins concrets peuvent override cette logique ; ce fallback marche pour powerline/minimal.
fn estimate_width(kept: &[(usize, SegmentRich)]) -> usize {
    kept.iter().map(|(_, s)| crate::term::display_width(&s.text) + 2).sum()
}

pub fn resolve_skin(name: &str) -> &'static dyn Skin {
    match name {
        "powerline" => &POWERLINE_STUB,
        _ => &POWERLINE_STUB,
    }
}
```

```rust
use super::{fit_segments, Skin};
use crate::config::POWERLINE_SEP;   // à extraire si besoin, ou inline `\u{e0b0}`
use crate::segments::{SegmentRich, SegmentRows};
use crate::term::{bgc, fgc, RST};
use crate::theme::Theme;

pub struct Powerline;

impl Skin for Powerline {
    fn name(&self) -> &'static str { "powerline" }

    fn render(&self, rows: &SegmentRows, _theme: &Theme, cols: usize, suffix: &str) -> String {
        // v0.5 : 1 row. Multi-row prévu v0.6+.
        let segments = rows.first().cloned().unwrap_or_default();
        let kept = fit_segments(&segments, cols, crate::term::display_width(suffix));

        let mut out = String::with_capacity(512);
        let mut prev_bg: Option<(u8, u8, u8)> = None;

        for seg in &kept {
            // Sép entre segments : prev_bg → seg.bg
            if let Some(pbg) = prev_bg {
                fgc(&mut out, pbg);
                bgc(&mut out, seg.bg);
                out.push('\u{e0b0}');
                out.push_str(RST);
            }
            bgc(&mut out, seg.bg);
            out.push_str(&seg.text);
            out.push_str(RST);
            prev_bg = Some(seg.bg);
        }
        // Terminer la powerline : dernier bg → fond neutre
        if let Some(pbg) = prev_bg {
            fgc(&mut out, pbg);
            out.push('\u{e0b0}');
            out.push_str(RST);
        }
        out.push_str(suffix);
        out
    }
}

pub static POWERLINE: Powerline = Powerline;
```

```rust
impl Skin for Rounded {
    fn name(&self) -> &'static str { "rounded" }

    fn render(&self, rows: &SegmentRows, _theme: &Theme, cols: usize, suffix: &str) -> String {
        let segments = rows.first().cloned().unwrap_or_default();

                out.push('\u{e0b6}');
                out.push_str(RST);

            out.push('\u{e0b4}');
```

### Task C6 : Skin `Bullet` (le plus complexe — utilise `SegmentKind`)

**Files :**
- Create : `src/skins/bullet.rs`
- Modify : `src/skins/mod.rs`

**Step 1 : Design**

Le bullet skin transforme les segments à jauge (Context, Limit5h, Limit7d, Cost) en ronds colorés `●` dont la teinte dépend du pourcentage (vert → jaune → rouge), suivi d'un label court. Les autres segments (Model, Folder, Git) rendent en style minimal.

C'est pour cela qu'on a `SegmentKind` : le bullet **pattern-matche** sur chaque kind et applique un rendu custom.

**Step 2 : Implémenter**

Créer `src/skins/bullet.rs` :
```rust
use super::{fit_segments, Skin};
use crate::segments::{SegmentKind, SegmentRich, SegmentRows};
use crate::term::{fgc, RST};
use crate::theme::{Rgb, Theme};

pub struct Bullet;

fn pct_color(pct: f64) -> Rgb {
    // 0 → vert, 50 → jaune, 100 → rouge. Interpolation 2 segments.
    let p = pct.clamp(0.0, 100.0);
    if p < 50.0 {
        // Vert → Jaune
        let t = p / 50.0;
        let r = (0.0 * (1.0 - t) + 255.0 * t) as u8;
        let g = 200;
        let b = 100 - (100.0 * t) as u8;
        (r, g, b)
    } else {
        // Jaune → Rouge
        let t = (p - 50.0) / 50.0;
        let r = 255;
        let g = (200.0 * (1.0 - t) + 80.0 * t) as u8;
        let b = 0;
        (r, g, b)
    }
}

fn render_segment(seg: &SegmentRich, out: &mut String) {
    match &seg.kind {
        SegmentKind::Context { pct, .. } => {
            fgc(out, pct_color(*pct));
            out.push('\u{25cf}'); // ●
            out.push_str(RST);
            out.push_str(&format!(" {:.0}%", pct));
        }
        SegmentKind::Limit5h { pct, .. } | SegmentKind::Limit7d { pct, .. } => {
            fgc(out, pct_color(*pct as f64));
            out.push('\u{25cf}');
            out.push_str(RST);
            out.push_str(&format!(" {}%", pct));
        }
        SegmentKind::Cost(usd) => {
            // Échelle arbitraire : $0.5+ = rouge, $0.1 = jaune, sinon vert.
            let pct = (usd / 1.0 * 100.0).min(100.0);
            fgc(out, pct_color(pct));
            out.push('\u{25cf}');
            out.push_str(RST);
            out.push_str(&format!(" ${:.2}", usd));
        }
        _ => {
            // Non-jauge : rendu minimal (fg = bg du segment)
            fgc(out, seg.bg);
            out.push_str(seg.text.trim());
            out.push_str(RST);
        }
    }
}

impl Skin for Bullet {
    fn name(&self) -> &'static str { "bullet" }

    fn render(&self, rows: &SegmentRows, _theme: &Theme, cols: usize, suffix: &str) -> String {
        let segments = rows.first().cloned().unwrap_or_default();
        let kept = fit_segments(&segments, cols, crate::term::display_width(suffix));
        let mut out = String::with_capacity(256);
        for (i, seg) in kept.iter().enumerate() {
            if i > 0 { out.push_str("  "); }
            render_segment(seg, &mut out);
        }
```

```rust
fn run_bin_with_settings(fixture_json: &str, cols: usize, theme: &str, skin: &str) -> String {
    let tmp = std::env::temp_dir().join(format!("ccfaststatus-golden-{}-{}", theme, skin));
    std::fs::create_dir_all(&tmp).unwrap();
    let cfg = tmp.join("ccfaststatus/config.toml");
    std::fs::create_dir_all(cfg.parent().unwrap()).unwrap();
    std::fs::write(&cfg, format!(
        "[theme]\nname = \"{}\"\n[skin]\nname = \"{}\"\n", theme, skin)).unwrap();

    let bin = env!("CARGO_BIN_EXE_ccfaststatus");
    let mut child = Command::new(bin)
        .env("COLUMNS", cols.to_string())
        .env("XDG_CONFIG_HOME", &tmp)
        .stdin(Stdio::piped())
        .stdout(Stdio::piped())
        .stderr(Stdio::null())
        .spawn()
        .expect("spawn");
    child.stdin.as_mut().unwrap().write_all(fixture_json.as_bytes()).unwrap();
    let out = child.wait_with_output().unwrap();
    std::fs::remove_dir_all(&tmp).ok();
    String::from_utf8_lossy(&out.stdout).trim_end_matches('\n').to_string()
}

fn check_matrix(name: &str, theme: &str, skin: &str) {
    let json = std::fs::read_to_string(fixture_path(&format!("{}.json", name))).unwrap();
    let suffix = format!("{}_{}_{}", name, theme, skin);
    let expected_path = fixture_path(&format!("{}.expected", suffix));

    let actual = run_bin_with_settings(&json, 200, theme, skin);

    if std::env::var("UPDATE_GOLDEN").is_ok() {
        std::fs::write(&expected_path, format!("{}\n", actual)).unwrap();
        return;
    }

    let expected = std::fs::read_to_string(&expected_path).unwrap();
    let n_expected = normalize(expected.trim_end_matches('\n'));
    let n_actual = normalize(&actual);
    assert_eq!(n_actual, n_expected, "snapshot mismatch for {}", suffix);
}
```
